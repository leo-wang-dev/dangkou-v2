开通客户 Telegram Bot

档口已由人工确认并开通服务。您继续在微信 Bot 管理商品和红线；客户通过您自己的 Telegram Bot 咨询。

开通前，请先在微信告诉助手老板的微信号或 Telegram 用户名，并按提示审批确认。至少设置一种联系方式后才能开通，客户触及红线时才能联系到老板。

① 打开官方 BotFather

在 Telegram 打开 @BotFather，点击 Message（发消息），进入聊天后发送 /newbot。微信内打不开时，请复制官方用户名到 Telegram 搜索。

② 设置名称并复制 Token

先填写机器人显示名称（例如“我的档口客服”），再填写您自己的用户名（例如 MyShopExample_bot，需未被占用并以 bot 结尾）。不要照抄截图中已注册的用户名。
看到 Done! 后，复制 Use this token to access the HTTP API: 下方的完整 Token；即使显示换行也要复制全，不要复制 t.me 链接。

③ 回到商家微信 Bot 开通
微信 · 您的档口助手绑定客户Bot [粘贴完整 Token]

只发送到您管理档口的微信 Bot 私聊。系统验证并绑定本档口，开通后返回客户访问链接。此页面无需填写 Token。

开通后，先打开客户 Bot 发送一张商品照片和规格数量，检查回复、采购笔记与 Excel，再将该 Bot 的链接或二维码提供给客户。

店铺联系方式、商品和红线仍在微信 Bot 补充。例如发送“客户问加急交货时转人工”，按提示确认规则后生效；触及已设置的红线时，客户 Bot 会发送档口联系方式。
