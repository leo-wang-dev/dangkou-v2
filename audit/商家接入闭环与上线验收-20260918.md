# 商家接入闭环复核与上线验收

2026-09-18 已按用户授权部署商家接入助手和独立客服运行服务。不能将此结果表述为所有真实商家客服已完成接待验收：当前尚无商家绑定独立 bot，真实 Telegram 客户接待仍待商家接入后验证。

## 复核发现与修复

1. 新商家缺少商品管理入口。新增对话命令“商品管理”，生成本商家专属、1小时有效的 HTTPS 管理链接。可新增修改商品、上传图片及审批已有工单；网关按商家隔离，隐藏内部服务密钥，拒绝路径穿越和跨店凭据。不会开放服务器文件导入路径、修改 bot 绑定或其他管理接口。
2. 已有档口从平台旧 bot 迁移需要人工跑脚本，无法完成自助接入。现支持一次性认领链接；仅对已经认领、旧绑定确为平台 bot、原 worker 已停止且收发队列排空的情况，在商家启用新 bot 时自动备份并迁移。其他旧 bot 更换继续要求管理员处理。
3. 照片候选“询价1”没有记录选定商品上下文。补上选项有效性校验、实时商品检查和上下文保存。
4. 已有档口迁移时可能使用新建空图片目录。已改为复用原档口图片目录。
5. 客服进程异常退出时缺少可见错误提示；已补充错误状态及重试说明。

## 真实业务闭环剩余项

用户通过一次性链接认领原有档口，填写真实店名及老板联系方式，并在BotFather创建独立客服bot，使用HTTPS页面绑定。之后“启用客服”，使用该独立bot验证商品查询、原图清单/Excel及转人工联系方式。这属于商家自己的账号配置及真实接待验收，不能使用平台助手Token代替。

阶梯报价本版仍为商家规则原文配置和展示，不计算订单价格；未填的商家业务红线不会默认生效。没有业务资料时不会编造价格或承诺。
