## 真实测试发现并修复的问题

1. **漏掉清楚的品牌与容量。**初版第一张结果只剩手写数字。调整为先读前景包装、再读价签；低信息结果有限重试。
2. **背景误入清单。**初版会多记牛油果瓶、白色背景罐和局部纸盒。增加对同一原图的第二遍复核，以主体标记控制入清单。
3. **截断价签被补成确定数字。**右侧软管曾被写为“3”。增加价签定位及边界检查：复核标为不完整、定位缺失/异常、框靠近照片边缘时，不能保留确定价格。这会保守地拒绝部分靠边但完整的价签，采购员可补充。
4. **复核反而将模糊价格猜成 7.25。**增加代码校验：初次结果模糊、两次金额不同或商品对应关系不明确时，最终必须保留模糊；禁止复核把不确定结果升级成精确金额。两遍都读错仍有可能，所以保留客户确认步骤。
5. **模型返回前置解释加 JSON 代码块，系统误认为没识别出来。**完善 JSON 提取，并统一字段、补齐未拍到项、保留数字 0。
6. **HTTP 成功但模型返回空内容。**客户端有限重试；持续为空则抛出明确错误，交由已有持久化收件队列重试，不作为成功结果消耗。最终四图验收中护发产品发生一次空响应导致的处理重试，记录保留，没有隐去。
7. **原验收脚本定位草稿不准确。**多图时按本次照片的实际条目核对；补改指令明确“第 1 条”，不把默认最后一条的修改误判为第一条失败。真实验收加入精确主体数量和截断价不能编造的检查，未放宽成“有返回就通过”。
