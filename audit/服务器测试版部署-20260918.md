## 验证结果

- 最终本地完整回归：377 通过、3 个外部测试跳过；详见 `round10/deploy-regression-final.log`。
- 服务器 API 健康检查、bot 身份检查、两端档口关联检查通过。
- 浏览器实际访问服务器 API：商品页切换 30 个剃须刀 / 44 个卷发棒，打开编辑窗口，确认没有阶梯报价字段。
- 浏览器客户清单：6 条记录、6 张图片加载成功；点击下载 Excel 后校验 6 行商品、6 张内嵌图片。没有 JavaScript 错误。证据在 `round10/server-browser/`。
- 服务器百炼真实模型政策检查 10/10 通过，真实照片识别调用成功。
- 服务器常驻 bot 已发送“服务器测试版-原有采购清单.xlsx”，发送队列 id=11，sent=1，attempts=0。
- Docker 和 amd64 解析镜像 `dangkou-parser:2.1.236` 已安装；复用原服务器解析供应商地址、专用密钥和 glm-5.3 配置。两份合成 Excel 同时通过真实容器解析，各产生 2 条商品、2 张图片，无错误，均独立生成待审批工单。
- 实际浏览器检查发现并修复：展开第二张工单后，第一张工单的编辑按钮会引用全局草稿和当前工单 ID，可能改错单。现按工单 ID 隔离草稿、类别和提交目标，并新增浏览器回归测试。服务器现场点击验证独立编辑及独立驳回通过；测试工单已驳回，原商品未被测试数据覆盖。

## 回退注意事项

停止服务器测试 bot 后才能恢复本地 bot。服务器开始接收新消息后，需要先备份并迁回最新 CS 数据和图片，不能直接用部署前备份启动旧实例，否则可能丢失新记录或重复处理。测试环境已有独立数据目录，停止测试服务不影响原生产数据库。
