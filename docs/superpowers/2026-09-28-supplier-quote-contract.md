# 商品供应商与报价接口（H5试用 Task2）

`product_dynamic.supplier` 是商品的独立供应商名。旧库加列时从分类供应商回填；既有显式商品值不随分类默认值修改。空值读取时兼容分类默认值。商家商品读接口、`/stats?full=true` 和客户商品投影均返回 `supplier`；商家直接保存使用 `changes.supplier`，AI 操作仍生成审批工单。模板审批保留供应商；客户标题只采用公开型号字段。

导入行使用顶层 `supplier`，来源顺序：行供应商、文档 `vendor`、分类默认供应商。商品匹配按分类内供应商、型号和规格；文件名不构成商品身份。价格/成本/库存/备注变更可更新同款，不同规格保留独立款。缺少必要规格、多个匹配对象或重复输入款式会抛出包含供应商、型号、行号的 `ValueError`，不任意更新。Task3可将这些错误转为逐行失败。

导入快照覆盖完整分类，保护跨文件名匹配到的记录。缺行不会生成下架草稿；旧工单中的缺行下架草稿也不执行。商品下架仍走商家明确操作。历史待审批工单如果旧快照缺少供应商或不能证明当前匹配范围未改变，会安全返回409并要求重新导入；已审批商品保留。没有现有商品且空快照仍有效的历史工单不一定失效。

`POST /quote` 保留 `path`，新增 `items` 和 `quantity_adjustment_note`。每项包含 `category`、`product_id`、`supplier`、`model`、`requested_quantity`、`quoted_quantity`、`pcs_per_carton`、`unit_price`、`amount`。单价按 Decimal 四舍五入至两位，再按实际整箱数量计算总额及定金。通知与引擎工具结果包含整箱数量调整说明。

报价映射保留原有型号/价格/箱规/颜色映射，新增可选的 `pcs_field`、`gw_field`、`nw_field`、`dims_field`，分别表示每箱数量、千克毛重、千克净重和厘米箱体尺寸。支持常见数字、PCS/CTN、件/箱和QTY箱规；不会猜测其他计量单位。
