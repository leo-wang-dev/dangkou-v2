## D. 自动化 Harness（不需用户）

- 商品数（剃须刀≈25 / 卷发棒=43 源文件真实型号数）
- 空型号=0、重复型号=0
- 图片配对 100%（硬线）、无虚构图名
- 四分类重导：改行=更新、删行=下架、加行=新增，全进审批
- 检索质量 Top1≥80% / Top3≥95%（曾实测 94%/100%）
- 报价单 openpyxl 读回：5 列头正确、图≥1

## 流程纪律（本次定稿附带）

1. 前端改动前必须与用户对齐——**不再串改**
2. 每次改动：TDD（先红后绿）+ JS 语法门禁 + 不绿不提交
3. 破坏性操作（清数据/清会话）只在用户明示后执行
