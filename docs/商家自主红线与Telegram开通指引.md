# 商家自主红线与 Telegram 开通指引

状态：2026-09-18 已按本文切换并部署到微信手测实例。微信管理模式没有平台默认价格红线；阶梯报价不做，客户商品介绍和采购笔记不展示价格。

## 已明确的产品原则

1. 平台提供商家填写、保存、确认和执行规则的基础能力，不替商家制定报价档位、底价或经营条件。
2. 场景清单是填写参考，不是默认红线。未填写、跳过、未确认的参考项不生效。不能预先全选，不能因引导问题出现某句话便将其自动加入红线。
3. 仅当当前问题符合商家明确设置的条件时，按该条件转人工，并发送已配置的老板 TG 与微信。客户主动要求人工另行处理，不需要先命中红线。
4. 未设置红线不等于允许编造答案。报价、交期、物流能力、定制和赔偿承诺只能依据商家提供的信息；缺失时明确说资料尚未提供，不能声称“触发商家红线”。
5. Telegram 账号和 bot 由商家自行开通、持有和管理；平台提供指引与现有档口的接入能力。

## 商家对话引导

开场：

> 哪些问题你希望客户来问时直接交给你？我可以按价格、付款、定制、物流、售后等方面逐项帮你整理。下面都是参考，可以只填需要的，也可以全部跳过。你没设置的内容不会作为转人工红线。

每次引导一类，允许商家用自己的话回答，不强制把全部例句填完。

| 类别 | 引导问题 | 参考场景，不默认启用 |
| --- | --- | --- |
| 价格与议价 | 哪些报价或议价情况必须由你处理？是否只针对特定商品或数量？ | 大量采购底价、长期优惠、同行价格、整批库存、样品费抵扣、让利点数、完整价格清单、各档位拿货政策 |
| 定制与打样 | 哪些定制问题可以依据已有资料回答，哪些需要你确认？ | 开模、打样费用和周期、免费样品、颜色色号、包装设计、标签品牌、尺寸、工艺、内部结构 |
| 付款条件 | 哪些付款方式或条件需要交给你？ | 月结、延长账期、赊账、部分定金、售后结款、信用证、付款优惠、定金比例、货款扣减 |
| 物流与交期 | 你希望哪些物流、仓储或交付承诺由你确认？ | 货代、指定仓库、拼柜混装、出货时间、加急、运费合并、海外代发、暂存、报关资料、运输责任 |
| 售后与质量 | 哪些售后问题必须由你接手？ | 次品赔付、批量退货、大货与样品不一致、质保、交期损失、海外运输破损 |
| 其他经营边界 | 还有哪些客户请求你希望亲自处理？ | 商家不经营的品类、品牌与认证相关请求、资料真实性、其他商家明确提出的条件 |

设置需保留商家实际限定条件。例如商家只填写“加急交期由我处理”，不能扩大成所有物流问题都转人工，也不能自动连带开启价格或售后规则。

### 保存与确认

1. 只整理商家明确选择或输入的内容，展示原话和拟生效规则。
2. 显示作用范围：全店或指定商品。商家没说明清楚时先澄清，不猜数量、价格或范围。
3. 商家确认后提交审批；审批前仍使用原规则。
4. 批准后立即生效；驳回则保持原规则。
5. “跳过本题”不清空已有设置；“删除某条”“清空所有红线”属于明确修改，展示差异并确认。
6. 默认空规则、清空后重启、未批准规则、未填写类别都不得重新出现系统预置红线。

示例：

> 商家：价格先不设，只把月结和加急交货交给我。
>
> Bot：拟设置两项：① 客户要求月结；② 客户要求加急交货。这两项转人工，其他参考项不启用。请确认。

## Telegram 商家开通指引

1. 使用商家自己的 Telegram 账号打开官方 [@BotFather](https://t.me/BotFather)。
2. 发送 `/newbot`，按提示设置显示名称和唯一 bot Username。
3. 保存 BotFather 返回的 API Token。Username 是客户访问入口，Token 是接入凭证，不放进对客资料或红线文本，也不要发到客户群。
4. 通过受控接入流程配置 Token，将 bot 身份绑定到该商家的现有档口；填写真实档口名称、老板本人 TG Username 和微信号。老板账号与 bot Username 是两个字段。
5. 从另一个客户账号打开该 bot，点击 Start，验证商品查询、拍照清单、Excel 导出以及已配置的转人工条件。
6. 商家保留 bot 管理权；接入已有 bot 时核查是否有其他程序正在消费消息，防止重复运行。

创建与管理操作依据：[Telegram 官方 BotFather 说明](https://core.telegram.org/bots/features#botfather)。当前项目仍是一个档口一套数据与 bot 绑定，更换已有 bot 需要迁移消息记录；不能将指引描述成已经提供了多商家自助开通后台。

## 实现状态及验收要求

- `catalog/db.py` / `catalog/cs.py` 已取消微信管理模式的默认红线播种和默认回退；迁移保留商家真实设置。
- `catalog/price_policy.py` / `catalog/csbot.py` 已取消用价格关键词无条件命中平台红线；规则为空时模型不能凭常识增加红线。
- `catalog/api.py`、审批页面和商家工具已支持查看、修改和明确清空商家规则，参考清单与生效规则分开显示。
- 阶梯报价不执行，也不对客户展示。历史字段仅作兼容，不能自行恢复自动报价。
- 同一句“能不能月结”，空规则时不应标为红线；商家设置并审批后应命中；删除并审批后应停止命中。
- 设置“加急交货转人工”不得误触发普通物流查询；未设置的定制、售后和价格场景不得因为出现在参考清单中就生效。
- 提示词诱导、旧队列重试和空规则重启不能恢复旧的默认红线。
