# 档口认领审核操作

已有档口必须经过原始登记资料匹配和持有人确认。新建空档口不会获得任何已有档口的商品库；本流程验证数据归属，不等于营业资质认证。

## 管理员操作

1. 打开 `/merchant/review.html`，使用管理员审核凭证。限时审核凭证只可访问认领资料登记与审核接口，不可签发档口邀请码或访问商品管理。
2. 根据原始登记表或原有档口微信记录，登记该档口的手机号或微信号，注明来源凭据和登记人。不能直接照抄申请人本次新填的号码作为底册。
3. 请申请人在接入 bot 发送 `核对联系方式 原登记手机号或微信号`。中国手机号可直接填11位，也可使用 +86；其他地区需包含国家区号。成功匹配只说明信息一致，不会授权。
4. 管理员通过底册中的原登记电话或微信联系持有人，确认申请的 TG 用户确实代表该档口。当前是人工联系核验，系统不自动发送短信或微信。
5. 刷新审核页面，核对申请 TG 数字 ID、底册版本和匹配结果。填写本次核验记录，确认已联系本人，再点击批准。申请人回复 `认证进度` 继续开通。

每个申请最多尝试核对5次。修改底册会清除旧匹配、重置核对次数并使该档口旧认证失效；相关运行权限暂停，需重新认证。拒绝或缺少原始资料时不应批准。

## 自动短信验证的边界

目前没有用户提供的可信手机号底册，也没有短信服务配置，因此尚未启用自动短信验证码。后续需接入真实短信通道，验证码只能发送到底册中的号码，不能发到申请人临时提交的新号码。不得用测试发送器假装完成真实验证。

## 凭证和数据

审核凭证只保存在页面内存，不写浏览器localStorage。限时入口通过URL片段传递，页面读取后清除，不进入HTTP请求或访问日志。可信登记信息仅管理员可读；申请人看不到底册号码。原始联系方式与公开的老板联系方式分开保存，修改店铺资料不会修改认证底册。
