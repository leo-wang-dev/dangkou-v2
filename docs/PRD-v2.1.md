## 1. 系统概述

档口商品管理系统，帮义乌档口商户管理商品、找货、报价。

**核心能力**：商家发厂家 Excel → AI 解析入库 → 客户发图找货 → 一句话出报价单 Excel。

**架构**：
```
微信 ⇄ dsh-engine（DeepSeek 主对话 + catalog-v2 插件）
         ↓ HTTP
       商品服务 dangkou-v2（FastAPI + SQLite）
         ↓ spawn
       解析 Sub Agent（Claude Code + glm-5.3）
```

## 2. 品类模板

每个品类一套独立模板（字段 + 提示词），**互不影响，可单独微调**。

| 品类 | 源文件 | 去重键 | 字段 |
|---|---|---|---|
| 剃须刀 (razor) | 剃须刀现货.xls | 产品型号 | 型号/描述/颜色/尺寸/彩盒/重量/箱规/报价 |
| 卷发棒 (curler) | 华岳电器.xlsx | ITEM.NO | 型号/装箱尺寸/装箱数/价格/电压/功率/发热体/材质/频率 |

内部货号：系统生成 `KS-XXXXXXXX`，商家内部管理用。

## 3. 产品流程

### 3.1 导入

```
商家发 Excel → AI 问品类 → 异步解析（Sub Agent）
→ 完成推送 + 审批链接 → H5 审批（逐行编辑/换图/驳回/单行通过）
→ 入库 + 图片落位 + 向量入池
```

**v2.1 变更**：
- 不做任何合并（每行=一个商品）
- 重导四分类保留：同型号=更新、不在新文件=下架

### 3.2 检索

```
发客户商品图 → 图向量匹配 → Top3-5 候选
→ 回复序号确认 / 换一批 / 发报价单（意图驱动，同义词均可）
```

### 3.3 报价单

```
确认后 → 多商品 + 各自数量 + 百分比调整
→ 从源 Excel 模板生成（公司抬头原样保留）
→ Qty + Amount + Total 自动计算
→ 微信发文件，商家直接转发客户
```

**价格计算**：`单价 = round(出厂价 × (1 ± pct%))`，`小计 = 单价 × 数量`

### 3.4 商品管理（H5）

- **商品页**：增/改/下架**直接生效**（用户本人=审批人）
- **审核页**：AI 操作（修改/下架/新增）走审批工单，显示改前→改后对比

### 3.5 统计查询（v2.1 新增）

微信直接问"一共有多少产品""卷发棒有几个"，AI 调统计工具回答。

## 4. 关键规则

| 规则 | 说明 |
|---|---|
| 出厂价 | 导入的唯一存储价格，字段名 `price` |
| 销售价 | 报价时实时计算，不存库 |
| 数量 | 报价时实时给，不存库 |
| 合并 | **不做任何合并**（v2.1 拍板：宁可多进让人驳回） |
| AI 写操作 | 必经审批工单 |
| H5 用户操作 | 直接生效（本人即审批人） |
| 图片 | 支持 png/jpg/webp/bmp/tif（tif 自动转 png）；微信 .bin 自动检测格式 |
| .xls 老格式 | 自动 soffice 转 .xlsx |

## 6. 验收标准

| 场景 | 验收点 |
|---|---|
| 导入 | 品类询问→异步→推送→审批；30行全进（不合并）；空型号=0；图片100% |
| 重导 | 改行=更新；删行=下架 |
| 检索 | Top1≥80% / Top3≥95% |
| 报价单 | 多商品+数量+百分比；原模板抬头；Qty/Amount/Total 正确 |
| 统计 | 总数/品类数量准确 |
| AI 操作 | 修改/下架/新增走审批生效 |
